# credit_scoring

## Требования

- Python версии, указанной в `pyproject.toml` проекта (не ниже 3.12 для данного скрипта).
- Poetry.
- Исходный log-файл с данными в формате JSON Lines.

## Установка

1. Клонируйте репозиторий и перейдите в каталог проекта:

   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. Установите зависимости проекта:

   ```bash
   poetry install
   ```

   Poetry установит зависимости, объявленные в `pyproject.toml`, и будет использовать `poetry.lock`, если он присутствует.

3. Проверьте доступность Python в окружении Poetry:

   ```bash
   poetry run python --version
   ```

## Запуск

Запустите скрипт из корневой директории проекта:

```bash
poetry run python <script_name>.py
```

Замените `<script_name>.py` на фактическое имя файла со скриптом.

После запуска программа запросит:

1. Путь к исходному log-файлу.
2. Директорию для сохранения `POS_CASH_balance.csv`.
3. Директорию для сохранения `bureau.csv`.

Указывайте пути к существующему исходному файлу и директории, в которых можно создавать выходные файлы. Выходные директории скрипт создаёт автоматически.

### Пример запуска

```text
Введите путь к log-файлу: D:\Data\input.log
Введите путь для POS_CASH_balance.csv: D:\Data\output\pos
Введите путь для bureau.csv: D:\Data\output\bureau
```

## Результаты

После завершения обработки будут созданы два CSV-файла:

- `POS_CASH_balance.csv` — данные о балансе POS-кредитов.
- `bureau.csv` — данные о кредитных записях из БКИ.

Фактические пути к файлам зависят от введённых директорий. В текущей реализации скрипт создаёт дополнительную вложенную директорию с именем файла без расширения.
