# Credit Scoring

Проект посвящён подготовке модели для задачи кредитного скоринга на основе датасета Home Credit Default Risk.

## Документация

- [Запуск генерации и проверка признаков](docs/feature_generation.md)
- [Запуск обработки логов](docs/logs_processor.md)

## Структура проекта

- `src/app/` — исходный код приложения.
- `scripts/` — вспомогательные скрипты.
- `docs/` — документация проекта.
- `data/` — входные данные и результаты обработки (локальные данные могут отсутствовать в репозитории).

## Технологии

- Python
- pandas
- Poetry
